审查规则

    
Strict keep
必须同时满足：图片本身支持该 speech-relevant evidence；只看 flat OCR 不足；source/target event 可稳定计分；类型属于颜色/图例关系、箭头/实体连接、空间/顺序/计数或其他真正语义视觉信息。

    
OCR control
图片有帮助，但帮助只来自 OCR 漏字、错字或小字识别。它可以保留作控制组，不能当作 vision > OCR 的 semantic evidence。

    
OCR 是否充分
把 OCR 当作无布局、无颜色、无箭头的纯文本。若这些文字已经足以预测或消解 speech 中的相关内容，选“是”。候选词没完整出现不代表 OCR 不充分；候选词出现也不必然代表 OCR 充分，关键看关系信息是否缺失。

    
Event 是否可计分
English source 必须包含明确、非泛化的事件；Chinese reference 必须有可辨认的对应表达。example、content、based 等泛词通常不可稳定计分。

    
机器提议
机器描述只能帮助发现提议错误，不能替代对 pixels 的判断。以 slide 实际内容为准。

    
输出
先完成 A 队列。若 strict keep 少于 30，再继续 B 队列。导出的 JSONL 可以包含 pending rows；后续只消费 completed rows。
